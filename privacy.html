Politique de confidentialité

Cette application est une automatisation interne et privée. Elle reçoit uniquement des notifications Gmail d'une seule boîte interne, afin d'avertir des outils internes. Aucune donnée n'est vendue, partagée ou utilisée à d'autres fins. Il n'y a aucun utilisateur externe. L'utilisation des données respecte la politique Google API Services User Data, y compris les exigences « Limited Use ». L'accès peut être révoqué à tout moment sur myaccount.google.com/permissions.

Privacy Policy

This application is a private internal automation. It only receives Gmail notifications for a single internal mailbox in order to notify internal tools. No data is sold, shared, or used for any other purpose. There are no external users. Use of data complies with the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
